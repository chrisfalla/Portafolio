# Portafolio Profesional Digital

## Descripción

El estudiante deberá diseñar y publicar un sitio web el cual funcionará como su **Portafolio Profesional Digital**. El sitio deberá presentar una estructura organizada, visualmente coherente y de fácil navegación. Desarrollado con **Astro** como framework estático.

## Estructura del Sitio

El portafolio deberá contener como mínimo:

### Página de Inicio
- Presentación breve del estudiante
- Descripción que permita comprender su perfil académico y profesional

### Sobre Mí
Información relacionada con:
- Formación académica
- Intereses profesionales
- Habilidades
- Competencias digitales
- Áreas en las que desea desarrollarse profesionalmente

### Competencias y Herramientas Digitales
- Presentación visual de las principales herramientas y tecnologías que conoce o ha utilizado durante su formación
- No será suficiente incluir únicamente los logotipos; deberá indicar brevemente para qué utiliza cada herramienta o qué competencia ha desarrollado con ella

## Requisitos Técnicos

El sitio deberá:

- Estar desarrollado en **Astro**
- Estar publicado y disponible mediante enlace
- Contar con navegación funcional
- Mantener coherencia visual
- Incorporar imágenes y recursos multimedia pertinentes
- Adaptarse adecuadamente a visualización desde computador y dispositivo móvil
- Utilizar textos elaborados y revisados por el estudiante
- Evidenciar criterios básicos de privacidad, seguridad e identidad digital

## Entregable

Enlace público al Portafolio Profesional Digital desarrollado en Astro.

## Objetivo

Aplicar herramientas de diseño y publicación web para construir una presencia profesional digital que integre competencias, experiencias y evidencias del proceso formativo.

## Comandos

| Comando                   | Acción                                           |
| :------------------------ | :----------------------------------------------- |
| `npm install`             | Instala dependencias                             |
| `npm run dev`             | Inicia servidor local en `localhost:4321`        |
| `npm run build`           | Construye sitio de producción en `./dist/`       |
| `npm run preview`         | Previsualiza la construcción localmente          |
| `npm run astro -- --help` | Ayuda del CLI de Astro                           |
